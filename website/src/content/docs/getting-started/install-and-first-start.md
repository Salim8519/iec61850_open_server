ScadaBench needs Windows 10 or 11 (64-bit) and 4 GB of RAM. You do not need Docker, Python or
Node.js. Everything is inside the app.

## Choose how to get the app

The download page offers two files:

- **Installer** (`ScadaBench-Setup`): the usual Windows setup. It adds ScadaBench to the Start menu.
- **Portable file** (`ScadaBench-Portable`): one `.exe` file that runs directly, with no install.
  Use it when you cannot install programs on a computer.

Both files are the same version and behave the same way.

## Install

1. Open the download page at [scadabench.com/download](/download/).
2. Press the button for the installer and save the file.
3. Double-click the file and follow the steps shown by Windows.
4. Open **ScadaBench** from the Start menu.

## Portable file

1. Download the portable file and save it in a folder you can find again.
2. Double-click it. ScadaBench opens in its own window.

## First start

The first time you open ScadaBench, it does three things:

1. It asks you to start the free trial or to enter a licence key. The trial lasts 7 days. The
   Licence and VMs section explains the options.
2. It opens the **guided tour**. The tour takes about one minute and shows the five places and the
   Run button. Press **Next** to move on, or **Skip tour** (or Esc) to leave it.
3. It opens the **Devices** place with an empty project. You are ready for
   [Your first run](/docs/getting-started/first-run/).

To see the tour again, click **Help** in the left menu, then **Take the tour**.

## Keep the window usable

ScadaBench is designed for a 1366 by 768 screen and above. On a smaller window, the whole layout
scales down to fit, so every control stays on screen.

## If the app does not open

Check the [Troubleshooting](/docs/troubleshooting/) section first. It covers the most common start-up
problems.
