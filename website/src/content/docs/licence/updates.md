ScadaBench can check whether a newer version is available.

## Check for an update

1. Open **Settings**.
2. Go to the **About** tab.
3. Find the **Updates** part. It shows your current version, for example **Version 0.1.37**.
4. Press **Check now**. The page says **Checking…** while it works.

If a newer version exists, press **Open the download page** and install it from there.

## Your projects and license

- Your projects stay in the data folder next to the app.
- Your license stays with this computer. You do not need a new key for the same computer.
