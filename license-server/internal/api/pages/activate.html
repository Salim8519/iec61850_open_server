Offline activation

Activate a PC
without internet

Use this page on any computer with internet. You get a small license file to copy, for example on a USB stick, to the substation PC.

In ScadaBench on the offline PC: Settings › License, then Offline activation, then Copy Machine ID.

Back in ScadaBench: Offline activation, then Load license file (or paste the file's text) and press Activate.

No license yet? Buy one.
