Offline activation

Activate a PC
without internet

Use this page on any computer with internet. You get a small license file to copy, for example on a USB stick, to the substation PC.

In ScadaBench on the offline PC: Settings › License, then Offline activation, then Copy activation code. The code lets the virtual machines on that PC use the license too. A plain 64-character Machine ID also works, but then virtual machines cannot use the license.

Back in ScadaBench: Offline activation, then Load license file (or paste the file's text) and press Activate.

Each license works on one computer only. It cannot be moved to another computer. Reinstalling Windows on the same computer is fine. A new computer or a new motherboard needs a new license.
