# Spec: Machine licensing and protected release

Decision: [ADR-0046](../decisions/ADR-0046-licensing-and-protected-release.md).
Change: [0069](../changes/2026/0069-licensing.md); trial hardening:
[0152](../changes/2026/0152-trial-hardening.md) (ADR-0046 addendum 2026-10-19); one computer for good, no backdoors (2026-10-21):
[ADR-0097](../decisions/ADR-0097-license-no-backdoors.md) (LIC-33 to LIC-38); hardware
machine ID, security-chip binding and online lease (Go engine only, 2026-10-21):
[ADR-0098](../decisions/ADR-0098-license-binding-tpm-lease.md) (LIC-50 to LIC-59).

## Purpose

Packaged Studio runs only on a computer with a valid license: a one-time 7-day trial or a
lifetime key locked to one PC. Development runs exactly as before, with no license.

## Behaviour contract

- **Modes:** development (source, `start-studio.cmd`) never checks a license and never
  touches the license folder. Packaged builds check in the backend and, independently, in
  the native workers of release builds.
- **Certificate:** `license.cert` is `{payload, signature}`; Ed25519 over the exact payload
  string; payload holds `email, expires_at, hwid, issued_at, kid, license_id, max_machines,
  type (trial|lifetime), version (1)`.
- **Valid when:** signature matches an accepted key, `version == 1`, `hwid` equals this
  computer, `now + 300 >= max(issued_at, latest observed time)`, and for trials
  `now < expires_at`.
- **Trial request:** the client also sends salted hashes of MachineGuid, system volume
  serial and firmware UUID (placeholders sent empty). Every usable part (at least two)
  matching an ended trial refuses; 2 of 3, or more than 3 new trials from one IP in 30
  days, only asks for a confirmed email (6-digit code; one trial per address; a mail
  outage waives the code). A running match continues the same trial. IP never refuses.
- **Trials only:** answers carry a signed `server_time`. The anchor, the newest genuine
  stamp and a missing-anchor mark are kept in a dot-file, `HKCU\Software\ScadaBench` and
  `license_state.json`. Rollback = more than 48 h behind the latest copy or the signed
  time; signed time past `expires_at` ends the trial. Server outages never stop a trial;
  only when every anchor copy and the stamp are gone is one online check asked for within
  3 days. Lifetime licenses keep the 300 s rule and stay offline-friendly.
- **One computer, for good (server side, ADR-0097):** each license works on one computer only
  and cannot be moved. `POST /api/v1/transfer` answers 410 `moves_disabled` (old 0.1.x apps
  still call it) and never reads or changes a key; activating a key that is bound elsewhere
  answers 409 `bound_elsewhere` with plain text and no hint to move. The owner CLI, admin API
  and owner page have no action that unbinds, frees or re-binds a key (`reset-hwid` is gone);
  `certificate` only re-creates the certificate for the machine the key is already bound to.
  Kept: `issue` (friend keys, optionally pre-bound to a Machine ID for a new key), `revoke`,
  `list`, `delete`, and the trial resets. Old `transfers` data in stored keys stays readable.
- **Signed verify answers:** `POST /api/v1/verify` takes an optional `nonce` (32 lowercase hex,
  else 400 `bad_request`) and still returns `status`, `certificate`, `time` and `server_time`
  for old apps. It adds `answer` = `{payload, signature}`, signed like certificates and time
  stamps (Ed25519, unpadded base64url, raw payload string). The payload keys are in this exact
  order: `hwid, kid, license_id, nonce, purpose ("verify-answer"), status
  (valid|revoked|moved|unknown), time, version (1)`. `hwid` and `license_id` repeat the request
  exactly as sent, `nonce` is `""` when none was sent. Empty and `TRIAL-` keys answer `valid`
  (signed too).
- **Customer wording (server pages, emails, website):** "Each license works on one computer
  only. It cannot be moved to another computer." "Reinstalling Windows on the same computer
  is fine." "A new computer, a new motherboard, or a reset of the computer's security chip
  (TPM) needs a new license." "No refunds after a license is activated. Use the free 7-day
  trial to test ScadaBench first." A refund before activation stays as the website states it.
- **Gate:** while unlicensed, packaged engineering API calls answer 402; the browser shows
  the activation screen (trial, key, buy, offline file). Saved projects are never touched.
- **Wording:** every state is words plus an icon; the reason says what to do next.
- **No backdoors (ADR-0097):** a license the server cancelled is remembered by ID in the
  same three places as the trial clock (`.revoked_ids`, `RevokedLicenses`, `revoked_ids`)
  and stays refused whatever `license.cert` says; licenses never move; a server verdict
  counts only when signed for the request just sent; a packaged build asks only its
  built-in server and refuses to start without its `.sig`; only the server key is accepted.

- **Machine ID v3, chip binding and lease (ADR-0098, Go engine and native guard; the frozen Python
  backend keeps the older ID):** `hwid = SHA256_HEX("scadabench-hwid-v3|" + firmware + "|" + board + "|" +
  extra)` from the SMBIOS system UUID and baseboard serial (placeholders count as `""`; the lowercased
  MachineGuid only when both are `""`). A certificate with `ak` is tied to the computer's TPM 2.0: at every
  evaluation the chip signs a fresh nonce and software checks it with the certificate's `ak`; no server, no
  time limit. A certificate with `lease_days` is a lease: it needs a valid signed verify answer within
  `lease_days` days (the server's `lease_token` rotates with every answer; a stale token is `moved` and
  cancels the copy). Anything that stops the chip proof at activation gives a lease, never an error. The
  status adds `binding` (`tpm`, `lease`) for these licenses only. The native guard checks the v3 ID and the
  certificate; the TPM proof and the lease are the Go backend's.
