# Runtime and API contracts

Flask application factory + Waitress serves bundled React assets on loopback.
Python 3.12 is bundled using PyInstaller one-folder packaging.
The native worker uses libiec61850 1.6.1 and binds an explicit address and port.
Source development and packaged launch use the same application services, project
format, defaults and native protocol behavior. Development adds Vite/Werkzeug reload
only; moving to a package requires no project or runtime parameter changes.

The launcher owns the coordinator and child workers. A worker crash must become
an explicit failed IED state. No silent restart or simulated success.

Public API prefix: /api/v1. Commands use JSON HTTP requests; /events streams SSE.
Events have monotonic IDs and clients recover stale cursors through a snapshot.
Private worker messages are versioned JSON frames on stdin/stdout. stderr is logs.
Workers advertise control-selection events as well as versioned updates and atomic
feedback; a missing capability stops startup as a stale-engine error.
Control feedback log entries retain the exact control reference, raw Boolean
`ctlVal`, node-specific interpreted action and mapped-feedback change outcome.

Signal updates are typed and acknowledged. MMS command acceptance and switching
completion are separate outcomes. Quality and timestamps travel with the value.
Reports are generated by the stack, not fabricated by the frontend.

Equipment operations address a canvas node. The coordinator resolves its imported
CDC-compatible command binding and delegates MMS control to the native path. The
native handler applies its own status atomically before acknowledging the command
and emits the raw Boolean `ctlVal` in a private `control_applied` event. A dedicated
coordinator consumer then writes every explicitly mapped equipment feedback point
through the sample writer. It runs outside the worker-reader thread, so cross-worker
feedback cannot deadlock command IPC. The same path handles Studio and external MMS
clients and uses SCL types plus stored bindings, never vendor-specific reference
names.
The public node operation accepts semantic Open, Close, Operate, Reset and Press
actions. Stored Trip command polarity resolves the raw Boolean wire value, while
its independent state polarity resolves mapped Boolean feedback.
Latching Push status uses the sample writer and does not invoke MMS Control.
State and command bindings remain independently optional. Multiple nodes may share
one control, and each node may map its own state without changing the command model.
Enhanced-SBO selection never moves a breaker in standard mode. An explicit,
off-by-default CONCEN compatibility profile is available only for enhanced-SBO
DPC mappings: origin `CONCEN` is inverted and a successful `SBOw` queues the
operation immediately. Raw and adapted values are logged; later matching `Oper`
is acknowledged without duplicate movement. Native selection callbacks publish
the full lifecycle with the imported timeout. `GET /api/v1/equipment/states`
rehydrates authoritative canvas state after SSE connection or resynchronization.

Every browser tab displays the same backend session identifier and project
revision. Project mutations publish `project_changed`; other tabs reload the
authoritative snapshot. Diagram writes carry the revision they edited, and stale
writes are rejected instead of replacing newer work.

Automatic sources use bounded per-IED sample batches with at most 20 independent
worker dispatch threads. Value and companion quality/time updates share a native
data-model lock. A fixed 100ms deadline schedules automation; Pause/Stop synchronize
with an active cycle. Logs flush control/runtime events immediately and signal
events in groups of 100; normal shutdown flushes all remaining buffered records.

Every new run has compact append-only `events-NNNN.jsonl` segments, an append-only
per-run `manifest.jsonl`, and an append-only root `runs.jsonl`. Start, segment-open
and close facts are new records; existing records are never rewritten. Automatic
pruning is disabled so application code never deletes recorded run evidence. Older
`manifest.json` run folders remain readable legacy evidence and are not migrated in
place. `studio/tools/query_runtime_logs.py` retrieves records by run, kind, IED,
reference or text without mutating them.

Late deadlines retain at most five overdue cycles; larger backlogs emit explicit
skipped-tick counts. Recovery evaluates current active time, not historical samples.
Unexpected cycle errors visibly pause automation without killing its scheduling
thread or stopping MMS. See [cadence decision](../decisions/ADR-0005-automation-cadence.md).

Run starts simulated workers and, through `acquisition/manager.py`, one read-only
`studio_live` session per real IED plus one GOOSE listener in lab mode (ADR-0030,
ADR-0031). Workers advertise `goose_aware`. Both executables write frames to a
private copy of stdout; vendor console output goes to stderr as diagnostics.

Stop tears down workers. Pause Automation freezes scheduled sources, not MMS.
Closing a browser does not stop a running experiment; exiting the launcher does.
