# ADR-0002: richer shared color palette

Accepted: user requested improved colors, 2026-09-09.

Keep the agreed layout, system font and no-gradient/offline design. Replace the
mostly white header with navy, strengthen blue selection/navigation treatments,
and introduce restrained teal/violet equipment-library accents through shared
tokens. All workspaces use this palette; do not create independent page themes.

Operational colors retain their meanings. Category accents are confined to the
library, while switching text and geometry convey equipment status. Deletion
uses a red danger control and explicit impact confirmation, not color alone.
No project format or protocol compatibility changes result from the color refresh.
Visual browser acceptance remains required separately from a successful build.
